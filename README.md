# OLESA — Лендинг для мастера по наращиванию ресниц

**Проект создан по заказу** — портфолио и лендинг для мастера по наращиванию ресниц Олеси.

> 📸 **Версия для портфолио** — урезанная демонстрационная версия без реальных фото и контактных данных. Все изображения — заглушки с `picsum.photos`.

---

## 📋 О проекте

Это современный одностраничный сайт с адаптивным дизайном, содержащий:

- **Hero-секция** с анимированным градиентом и статистикой
- **Раздел услуг** — 6 типов процедур с ценами и временем выполнения
- **Портфолио** — галерея работ (заглушки)
- **Об авторе** — информация о мастерстве и сертификатах
- **Прайс-лист** — интерактивные вкладки по категориям
- **Отзывы клиентов**
- **Памятка по уходу**
- **Частые вопросы (FAQ)**
- **Форма записи** с валидацией
- **Карта проезда** с кнопками навигатора
- **WhatsApp & Telegram** — быстрые способы связи

---

## 🛠 Технологии

- **HTML5** — семантическая верстка, accessibility
- **CSS3** — CSS-переменные, Flexbox/Grid, анимации, `backdrop-filter`
- **Vanilla JS** — без фреймворков, оптимизированная производительность
- **Иконки** — inline SVG
- **Шрифты** — `Outfit` (Google Fonts)

## 🎨 Особенности реализации

- **Smooth scroll** — плавная прокрутка при переходах
- **IntersectionObserver** — анимации появления элементов при скролле
- **Sticky header** — меняет фон при прокрутке
- **Lightbox** — увеличение фото в модальном окне
- **Form validation** — проверка имени и телефона
- **Mobile-first** — адаптивная верстка для всех устройств
- **Reduced motion** — поддержка предпочтений доступности
